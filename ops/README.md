# APQueue — ดูแลระบบเครื่องแม่ข่าย (ops)

เขียนสำหรับคนดูแลเครื่องที่หน้างาน ไม่ใช่คนเขียนโค้ด — ทุกอย่างทำจาก **ไฟล์เดียว: `ops\apqueue.bat`**
(ติดตั้งระบบแบบหลายเครื่องทั้งหมด ดู [วิธีติดตั้งระบบจริง.md](../วิธีติดตั้งระบบจริง.md))

---

## ติดตั้งเครื่องแม่ข่ายใหม่ (มีอินเทอร์เน็ต)

1. ดาวน์โหลดไฟล์ [`ops/apqueue.bat`](https://github.com/AndamanDev/apq_siro/raw/main/ops/apqueue.bat) ไปวางที่ Desktop (หรือก๊อปจาก USB)
2. ดับเบิลคลิก → กด **Yes** เมื่อ Windows ขอสิทธิ์ผู้ดูแล
3. ไฟล์จะทำให้เอง (ทำซ้ำได้ ขั้นที่ทำแล้วจะข้าม):
   - ติดตั้ง **Git** และ **Node.js** (ผ่าน winget) ถ้ายังไม่มี
   - ดาวน์โหลดโปรแกรมจาก GitHub ไปไว้ที่ `D:\apqueue` (ไม่มีไดรฟ์ D → `C:\apqueue`)
   - ลงไลบรารี · สร้าง `kiosk\config.json` · เปิดไฟร์วอลล์พอร์ต 8888
   - ตั้งให้ server เปิดเองตอน login + สำรองข้อมูลทุกคืน 23:30 (Task Scheduler)
   - เปิด server และแสดง IP ให้เครื่องจอ/เครื่องห้อง
   - วางไอคอน **APQueue** บน Desktop
4. แก้ชื่อเครื่องพิมพ์ใน `kiosk\config.json` (คู่มือติดตั้ง ข้อ A7) แล้วเปิด Kiosk จากเมนู

> ถ้า repo ตั้งเป็น private: ลิงก์ในข้อ 1 ใช้ไม่ได้ (ก๊อปไฟล์จาก USB แทน) และตอนดาวน์โหลดครั้งแรก Git จะเปิดหน้าต่างให้ล็อกอิน GitHub
> เครื่องไม่มีเน็ต → คัดลอกโฟลเดอร์ทั้งก้อน (รวม `node_modules`) ไปวาง แล้วดับเบิลคลิก `ops\apqueue.bat` — ใช้ได้ทุกข้อ ยกเว้น "อัปเดตระบบ"

| | **ดูที่อยู่เครื่องแม่ข่าย (IP)** | ตั้งเครื่องจอแสดงผล / เครื่องประจำห้อง |
| | **เปิดจอแสดงผลบนเครื่องนี้** | ใช้เครื่องแม่ข่ายต่อทีวีด้วย |

## ระบบเปิดเองอย่างไร

งาน Task Scheduler **APQueue** (ตอน login) → `ops\tools\run-server.js` ทำงานเบื้องหลังไม่มีหน้าต่าง
- server ตาย → เปิดใหม่เอง (รอ 3 → 6 → … สูงสุด 60 วินาที)
- เปิดซ้ำ / มี `start-server.cmd` เปิดอยู่แล้ว → ไม่เปิดซ้อน
- ใช้แทน shortcut ของ `start-server.cmd` ใน `shell:startup` (ตอนตั้งจะลบ shortcut เดิมให้) — `start-server.cmd` ยังดับเบิลคลิกใช้ได้เหมือนเดิม

⚠️ ต้องมีคน login Windows ก่อน server ถึงจะเปิด — ตั้ง login อัตโนมัติ: `Win+R` → `netplwiz` → เอาติ๊ก "Users must enter a user name and password" ออก

| ไฟล์ | อะไร |
|---|---|
| `logs\server.log` | ข้อความจาก server (รอบก่อน: `server.prev.log`) |
| `logs\start.log` | เวลาที่เปิด / server ดับ |
| `logs\backup.log` | ผลการสำรองแต่ละครั้ง |
| `backup\queue-<วันเวลา>-<เหตุผล>.db` | ไฟล์สำรองฐานข้อมูล (เก็บ 30 วัน อย่างน้อย 7 ไฟล์) |
| `backup\assets\` | สำเนาวิดีโอ/โลโก้ที่อัปโหลด |

**ย้ายเครื่อง:** ติดตั้งเครื่องใหม่ด้วย `apqueue.bat` → ก๊อปโฟลเดอร์ `backup\` จากเครื่องเดิมมาวาง → เมนู **กู้คืนข้อมูล** → ตั้ง IP เครื่องใหม่ให้ **ตรงกับ IP เดิม** ที่เราเตอร์ (เครื่องจอ/ห้องไม่ต้องแก้)

> ไฟล์สำรองอยู่ในเครื่องเดียวกับระบบ — ฮาร์ดดิสก์เสียก็หายพร้อมกัน ควรก๊อปโฟลเดอร์ `backup\` ลง USB เป็นระยะ

## สำหรับนักพัฒนา: ปล่อยรุ่นใหม่

แก้โค้ด → `git push` ขึ้น `main` → ที่เครื่องหน้างานกดเมนู **อัปเดตระบบเป็นรุ่นใหม่**
- ไม่ต้องเขียน migration แยก — `server/src/db/connection.js` ปรับโครงตารางเองตอนเปิด (เพิ่ม `ALTER TABLE` ที่นั่น)
- เพิ่ม/เปลี่ยนไลบรารี → commit `package-lock.json` ด้วย เมนูจะ `npm ci` ให้เองเมื่อไฟล์นี้เปลี่ยน
- ห้าม commit `server/data/*.db` · `kiosk/config.json` (ค่าของแต่ละเครื่อง — อยู่ใน `.gitignore` แล้ว)
